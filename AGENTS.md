# Project Guidance

## User Preferences

- Preserve the existing Norwood visual language and existing export authorization/schema
- Minimum backend change only if strictly required; do not create permanent server-side export files
- Read-only portability work: no reseeding, no destructive migration, no changes to existing media records
- Never expose internal storage identifiers or security data in exports
- Testing boundary: compile/type-check plus focused export/bundle tests, maximum 2 retries, then stop and report

## Verified Commands

- **typecheck**: `pnpm typecheck`
- **fix**: `pnpm fix`
- **build**: `pnpm build`

- The Phase 5C-H1 export-instance state (exportInstances, exportMediaBindings) is intentionally not exposed via OQL, following the exportAudit precedent, because it stores raw family ids and internal media source keys with no public read endpoint.
